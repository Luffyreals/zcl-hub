Tải bản phát hành

Tải bộ cài đặt mới nhất từ trang GitHub Releases (chọn ZCL Teleport hoặc ZCL Remote).

2

Khởi chạy trên các máy tính

Chạy file `.exe` trên cả 2 máy tính cần kết nối (cùng chung mạng Wi-Fi hoặc dây LAN).

3

Bắt đầu làm việc

Mở ứng dụng, nhập mã PIN hoặc chọn máy tính tìm thấy để bắt đầu làm việc ngay.

1

Mở trình duyệt

Mở trang web này trên trình duyệt Chrome, Edge hoặc Safari.

2

Cài đặt PWA offline

Chuyển đến phần [ZCL Web Studio] và bấm 'Cài đặt ứng dụng' (PWA) để dùng offline.

3

Kết nối P2P tức thì

Kéo thả file hoặc nhập IP máy chủ để kết nối trực tiếp không cần cài thêm phần mềm.

1

Clone Repository

Clone kho mã nguồn từ GitHub: `git clone https://github.com/Luffyreals/zero-cloud-lan`

2

Cài đặt Dependencies

Cài đặt môi trường Python 3.11+ và chạy `pip install -e .`

3

Chạy lệnh CLI

Chạy lệnh CLI: `zcl-remote --host 0.0.0.0` hoặc `zcl-teleport --share`

GIẢI ĐÁP THẮC MẮC

Câu hỏi thường gặp

Hoàn toàn không. ZCL được thiết kế từ gốc để chạy độc lập 100% trong mạng cục bộ. Ngay cả khi nhà bạn bị mất mạng Internet hoặc đứt cáp quang biển, các máy tính kết nối chung một cục router/switch Wi-Fi vẫn truyền file và điều khiển nhau với tốc độ tối đa.
ZCL sử dụng giao thức mDNS (Multicast DNS) với định danh `_zcl._tcp` để tự động phát hiện các thiết bị ZCL đang hoạt động trong cùng subnet. Ngoài ra, bạn luôn có thể kết nối trực tiếp thông qua địa chỉ IP nội bộ (ví dụ: `192.168.1.15`) hoặc quét mã QR.
Ở các phần mềm truyền thống (như TeamViewer/UltraViewer), khi bạn di chuột, tọa độ phải gửi lên server rồi chờ hình ảnh màn hình phản hồi về mới thấy chuột di chuyển (trễ 150ms - 300ms gây chóng mặt). ZCL Remote vẽ con trỏ chuột cục bộ tức thì với độ trễ 0ms dựa trên phản hồi phần cứng máy bạn, tạo cảm giác mượt như ngồi trước máy thật.
Không một byte dữ liệu nào rời khỏi mạng của bạn. Các ứng dụng ZCL không có relay server, không có máy chủ telemetry thu thập thói quen sử dụng, và toàn bộ mã nguồn đều công khai theo giấy phép GPL-3.0 để cộng đồng kiểm tra.
Trong lần đầu tiên mở ứng dụng, Windows Defender Firewall sẽ hiển thị hộp thoại hỏi quyền truy cập mạng. Bạn chỉ cần tick chọn 'Private networks' (Mạng riêng tư) là ứng dụng có thể truyền nhận mượt mà trong phòng.
